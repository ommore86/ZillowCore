> **"The Autonomous Real Estate Operating System"**  
> EstateOS AI is a production-grade, hyper-scale, multi-tenant enterprise real estate platform designed to replicate and completely re-architect real estate consumer listing, programmatic valuation, asset management, and marketplace operations into an autonomous agentic operating system.

---

## 🌟 Key Capabilities

### 1. ZillowCore Core Engine (Primary PDF Specification)
- **Neural Geo-Spatial Query Router (NGQR):** Supersedes legacy SQL relational queries generated by client-side dropdown maps. Parses conversational intent (e.g. *"Find a luxury home in Northeast Bhopal under ₹2,00,00,000"*) directly into PostGIS bounding-box polygons, semantic visual embeddings, and sub-50ms execution resolutions.
- **Multimodal Valuation Engine (MVE — Autonomous Zestimate):** Computes continuous asset valuations by extracting interior computer vision features (Italian marble, stone countertops, distressed hardwood, natural lighting) and synthesizing them with satellite infrastructure ratings and macroeconomic benchmarks with an **Active Confidence Interval**.
- **Autonomous RESO / Data Ingestion Sandbox:** Self-healing data pipeline that detects schema drifts from upstream Multiple Listing Services (MLS), synthesizes parsing adapters in Rust/WASM, and stream-tests against historical mock caches for a 100% data extraction matching score without human intervention.
- **Property Master Ledger (`property_master_ledger`):** High-throughput data fabric storing geo-location points (SRID 4326), 1536-dimensional interior visual vectors with HNSW indexing, and continuous valuation confidence matrices.

### 2. Enterprise SaaS Modules (EstateOS Core)
1. **Executive Dashboard:** Central command center displaying live relational metrics (Total Properties, Occupancy %, MRR, NOI, Outstanding Receivables, Maintenance SLAs, and Revenue Trends).
2. **Property & Unit Management:** Residential, commercial, industrial, retail, office, plots, apartments, villas, warehouses, and multi-units with PostGIS coordinates, amenities, and bulk CSV export.
3. **CRM & 6-Stage Kanban Pipeline:** `New Lead` → `Contacted` → `Qualified` → `Site Visit` → `Negotiation` → `Converted`. Powered by AI lead scoring and customer interaction timelines.
4. **Lease & Rental Management:** Digital tenancy agreements, automated 5% annual escalation calculations, late fee schedules, and simulated electronic signatures.
5. **Financial Accounting & Invoicing:** Double-entry journal ledgers, invoices with 18% statutory GST calculation, verified payment settlements, and real-time Profit & Loss (P&L) statements.
6. **Maintenance & Facility Operations:** Tenant request intake with automated AI category and urgency classification, SLA assignment, and contractor work order dispatch.
7. **Sales & Deals:** Sales transaction pipeline, buyer-seller matching engine, and broker commission distributions.
8. **Document Vault & OCR:** Document categorization, OCR clause and milestone extraction, and compliance checklists.
9. **Vendors & Human Workforce:** Approved vendor network with trade categories, verification status, and 5-star ratings.
10. **Business Intelligence Reporting:** Interactive metric charts, CSV export, and automated C-level executive operations briefings.

### 3. AI-Native Multi-Agent Orchestrator
- **LangGraph Multi-Agent Architecture:** Centralized Master Orchestrator coordinating **24 specialized domain agents** across Management, Property, Sales, Finance, Maintenance, Legal, and Operational domains.
- **Agent Control Center:** Real-time agent status, execution duration, token and cost tracking, and persistent task execution logs.
- **Human-in-the-Loop Approvals:** Mandatory sign-off queue for sensitive actions (lease terminations, debt write-offs, major capital expenditures).

### 4. Omnipresent AI Command Center (`Ctrl+K`)
- Conversational command palette available throughout the application executing multi-stage instructions with visible execution traces.

### 5. Agentic Workflow Automation Builder
- Visual state machine builder supporting event triggers, condition trees, AI agent nodes, and manual execution triggers.

### 6. Developer Platform & Desktop Application
- **Enterprise REST APIs:** OpenAPI/Swagger compliant endpoints under `/api/v1` with API key management, rate limiting, and webhooks.
- **Native Desktop Application:** Tauri bundle configuration for Windows with native window controls, desktop notifications, and zero-latency local caching.

## 💻 Technology Stack

- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Recharts.
- **Backend:** Python 3.10+, FastAPI, Pydantic v2, SQLAlchemy 2.0, Uvicorn.
- **Database:** PostgreSQL with PostGIS and pgvector (SQLite with custom spatial math primitives for zero-dependency local testing).
- **AI Orchestration:** LangGraph, Multi-Agent State Machine, 1536-dim normalized vector embeddings, deterministic LLM fallback engine.
- **Desktop:** Tauri v1.8 / Native WebView2 desktop wrapper.
- **Deployment:** Docker, Docker Compose, Render Blueprint (`render.yaml`).

## 🚀 Quickstart & Development

### 1. One-Click Docker Setup
```bash
docker-compose up --build -d
```
- Web Application: `http://localhost:3000`
- API Platform & Swagger: `http://localhost:8000/docs`

### 2. Manual Development Setup

#### Backend:
```bash
cd backend
python -m pip install -r requirements.txt
$env:PYTHONPATH="backend"  # PowerShell (or export PYTHONPATH=backend on Unix)

# Initialize database schema and multi-city seed data
python -m app.services.seed_data

# Start FastAPI server
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

#### Frontend:
```bash
cd frontend
npm install
npm run dev
# Starts at http://localhost:3000
```

#### Native Desktop Application:
```bash
cd desktop
python run_desktop.py
# Or compile installer: .\build_windows_installer.bat
```
